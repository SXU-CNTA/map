# 使用

正常登录后可见应用列表 直接点击使用

这是常用应用的登录位置 **请不要输入账密 直接点击统一认证标志完成登录**

![2c7dc244-1b2c-4fb6-abd9-df6d6998d66a](https://www.gwy.fun/blog_ima/blog/2c7dc244-1b2c-4fb6-abd9-df6d6998d66a.png)

![8edb2320-bf4b-4328-a99d-adb2d7b46620](https://www.gwy.fun/blog_ima/blog/8edb2320-bf4b-4328-a99d-adb2d7b46620.png)

因群组权限无法共享 您第一次登录这些应用获得的都是协会统一默认权限

**若您需要堡垒机的相关主机运维权限/网盘文件修改上传权限 请联系会长/技术部部长副部长等**

**网盘权限同步有延迟 若您为技术部成员/志愿队成员却没有获得相应存储的访问权限 请耐心等待**
