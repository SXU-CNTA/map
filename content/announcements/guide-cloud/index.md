# 写在前面

欢迎使用 山西大学计算机与网络技术协会（以下简称“本社团”）提供的云服务及虚拟机资源。为了保障服务器的稳定运行及全体成员的权益，请在申请和使用前仔细阅读本协议。

**一旦您申请或开始使用本服务，即视为您已阅读、理解并同意接受以下全部条款。**

#### 服务性质与定位

- **非商业性与尽力而为：** 本服务是本社团利用现有资源为社团成员免费提供的学习、测试和研究环境。本服务**非商业级应用**，本社团将“尽力而为”地维护其运行，但不提供任何关于服务可用性、无故障运行时间（SLA）的承诺或保证。
- **用途限制：** 本服务仅限用于编程学习、合法开源项目部署、学术研究及社团相关活动，严禁将其作为生产环境存放极其重要或无法挽回的业务。

#### 数据安全与备份

- **自行备份：** **用户须对存储在****虚拟机****上的所有数据自行负责。** 本社团不提供定期的数据备份服务。
- **数据丢失免责：** 因硬件故障、断电、网络波动、不可抗力、黑客攻击或社团管理员在维护过程中的不可预见失误，导致的用户数据丢失、损坏或泄露，**本社团及相关管理人员概不承担任何法律责任及赔偿责任。**

#### 行为规范与合规性

使用本服务必须严格遵守国家法律法规及山西大学**校园网络使用管理规定**。**严禁使用本服务进行以下行为（一经发现，立即封号并删除数据）：**

- **违规外发流量：** 进行任何形式的网络攻击（如 DDoS、端口扫描、暴力破解）。
- **侵权与违法内容：** 搭建违规网站、代理服务器（用于翻墙等）、存储或传播色情、涉政、盗版版权文件等违反法律法规的内容。
- **恶意占用资源：** 运行任何加密货币挖矿程序（如挖比特币、门罗币等），或长期恶意跑满 CPU、内存及网络带宽。
- **账号转借：** 将分配到的虚拟机账号、密码或私钥转借、出租或出售给其他人。

#### 资源回收与服务终止

- **服务终止：** 本社团保留随时修改、暂停或永久终止该服务的权利（例如服务器硬件损坏且无预算更换、学校收回网络权限等），届时将尽量提前通知用户导出数据，但对因服务终止造成的损失不承担责任。

#### 安全与隐私

- **用户安全责任：** 用户需自行负责虚拟机的系统安全（如定期更新补丁）。因用户自身安全措施不到位导致虚拟机被黑客入侵、沦为“肉鸡”，责任由用户自行承担，且社团将立即关停该机器。
- **管理权限：** 虽然本社团尊重成员隐私，不主动审查用户数据；但在面临校园网网络中心警告、突发安全事件或涉嫌违法违规时，管理员有权对该虚拟机的网络流量进行监控，甚至在必要时重置密码进入系统排查问题。

#### 最终解释权

- 本免责声明及协议的最终解释权归山西大学计算机与网络技术协会所有。
